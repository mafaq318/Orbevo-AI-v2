# Orbevo-AI-v2

## Pre-Requisites

- Install Anaconda3 (create a new environment if needed)
- Install Git Bash and add conda to Git Bash Path (https://discuss.codecademy.com/t/setting-up-conda-in-git-bash/534473)
- Adapt third_dep_win.sh script with Env Name

## Setup

 - Run`make setup_linux_env` to setup all the rest dependencies in your host linux machine
 - Run`make setup_win_env` to setup all the rest dependencies in your host linux machine

## Run
Source the python env that we setup before and run make
 - . env/bin/activate
 - make
